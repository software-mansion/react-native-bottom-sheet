# Position tracking

Use `onPositionChange` to observe the sheet’s current position. It is a standard
native event; read the distance from the bottom of the sheet’s host to the top
of the sheet from `event.nativeEvent.position`, in layout units (points on iOS,
dp on Android, and CSS pixels on the web). For a modal sheet the host fills the
screen; for an inline sheet it is the sheet’s container. The same event also
carries `event.nativeEvent.index`—the fractional detent index in
`0..(detents.length - 1)` (`0` at the shortest detent, `1` at the next, and so
on, interpolated in between)—the continuous counterpart of `onIndexChange`,
handy for driving a backdrop or per-detent animation without knowing the sheet’s
height.

```tsx
<BottomSheet // Or `ModalBottomSheet`.
  index={index}
  onIndexChange={setIndex}
  surface={/* ... */}
  onPositionChange={(event) => {
    console.log(event.nativeEvent.position, event.nativeEvent.index);
  }}
>
  {/* ... */}
</BottomSheet>
```

A [`lazy`](modal-sheets#lazy-content) sheet emits no `onPositionChange` events
while it is unmounted, from the moment it settles at a closed detent until it
opens again. Handle the closed state from `onSettle` if you need it.

## With Reanimated

To keep the latest position in a Reanimated shared value, update it from the
callback:

```tsx
const position = useSharedValue(0);
```

```tsx
<BottomSheet
  index={index}
  onIndexChange={setIndex}
  surface={/* ... */}
  onPositionChange={(event) => {
    position.value = event.nativeEvent.position;
  }}
>
  {/* ... */}
</BottomSheet>
```

Because `onPositionChange` is a native event, you can also handle it on the UI
thread. Pass `Animated.createAnimatedComponent` to `wrapNativeView`—the library
applies it to the native sheet view—and give `onPositionChange` a worklet
handler from `useEvent`:

```tsx
import type { NativeSyntheticEvent } from 'react-native';
import Animated, { useEvent, useSharedValue } from 'react-native-reanimated';
import {
  BottomSheet,
  type PositionChangeEventData,
} from '@swmansion/react-native-bottom-sheet';
```

```tsx
const position = useSharedValue(0);
const detentIndex = useSharedValue(0);

const onPositionChange = useEvent<
  NativeSyntheticEvent<PositionChangeEventData>
>(
  (event) => {
    'worklet';
    position.value = event.position;
    detentIndex.value = event.index;
  },
  ['onPositionChange']
);
```

```tsx
<BottomSheet // Or `ModalBottomSheet`.
  index={index}
  onIndexChange={setIndex}
  surface={/* ... */}
  wrapNativeView={Animated.createAnimatedComponent}
  onPositionChange={onPositionChange}
>
  {/* ... */}
</BottomSheet>
```

`wrapNativeView` keeps the animated wrapper on the native sheet view itself, so
the worklet binds on first render—for both inline and modal sheets—without the
library depending on Reanimated. Pass a stable function (such as
`Animated.createAnimatedComponent`), not an inline lambda.

Inside the worklet, Reanimated unwraps the native event, so you read
`event.position` directly rather than `event.nativeEvent.position`. The handler
runs on the UI thread on every frame the sheet moves.

## Pinning content to the bottom

On iOS and Android, use `bottomAnchoredContent` on `BottomSheet` or `ModalBottomSheet` for a view
that should stay at the card's bottom edge during a drag and during the settle
animation. The slot is laid out against the largest detent. Shorter detents clip
it, so a list inside keeps the same viewport size during motion. The sheet lays
out its regular children above the slot in the drawing order and uses those
children to measure a `'content'` detent.

### Setting the top edge of the visible content

Set `contentClipTopInset` on an open detent to move the top edge of the
visible and interactive area of `bottomAnchoredContent` down from the card's top.
The slot keeps its layout size and its bottom anchor. The native host
interpolates the boundary between detents in step with the card animation.
The default is zero. When detents resolve to the same height, the last one
at that height supplies the inset in both directions.

Use this when another part of the sheet occupies the same area as content
whose layout needs to remain stable. An opaque overlay covers the content
and replaces any translucency or blur in that area with a solid fill. The
clip defines a shared boundary for drawing and touch input independently
of the surface material.

```tsx
<BottomSheet
  detents={[
    0,
    { value: '50%', contentClipTopInset: 48 },
    { value: '100%', contentClipTopInset: 64 },
  ]}
  index={index}
  onIndexChange={setIndex}
  bottomAnchoredContent={<Conversation />}
>
  <Header />
</BottomSheet>
```

The iOS-only alias `iosBottomAnchoredContent` is used when
`bottomAnchoredContent` is null or undefined. On the web, render the composer in the regular children.
